# 0001 - Privacy First Local Workflow

## Status
Accepted

## Context
The project handles operational notes, screenshots, incident data, and transcript text that may contain sensitive information.

## Decision
Use a local-first workflow where raw/source artifacts and generated caches are excluded from version control.

## Consequences
- Improves data safety for public sharing.
- Requires local setup for credentials and source files.
- Documentation and templates must stay clear and reproducible.
