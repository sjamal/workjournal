# ADR 0002: Consolidated Timeline And Export

- Status: Accepted
- Date: 2026-07-31

## Context

The project has two consumption modes:

1. Interactive review in the dashboard.
2. Non-interactive monthly export for Confluence.

Historically, these flows were generated by separate logic paths, which caused drift and inconsistent content.

## Decision

Use a shared timeline/data model for both outputs:

- `scripts/compile_dashboard.py` builds timeline rows and interactive HTML.
- `scripts/generate_journal.py` uses the same consolidated timeline model for batch table output.

## Consequences

- Dashboard and text export now align on included data.
- Export defects are easier to diagnose because both outputs share the same source model.
- Changes to source precedence can be implemented in one place.
